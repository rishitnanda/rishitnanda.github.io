# Rishit Nanda - Personal Portfolio

Welcome to my personal portfolio website. This space serves as a central hub for my projects, technical experiments, and professional background in software engineering, systems programming, and interface design.


## Tech Stack

*   **Frontend**: HTML5, Vanilla CSS3 (custom variables, grid, flexbox), Vanilla JavaScript (ESM modules).
*   **Contact Form Backend**: Serverless email routing via Web3Forms API.
*   **Design Elements**: Custom SVG icons, embedded typography, CSS 3D tilt micro-interactions, responsive fluid typography.

## Local Development

The frontend is completely static. You can run it locally using any basic static file server:
```bash
# In the web/ directory
npx serve .
```

To enable the contact form, simply generate a free access key from [Web3Forms](https://web3forms.com/) and replace `"YOUR_ACCESS_KEY_HERE"` in `script.js`.
